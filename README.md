# 华南地区植物生态效益自动计算与图表生成器

> 一个基于 Streamlit 的交互式网页工具，用华南地区实测文献数据 + AI 文本生成，
> 辅助风景园林种植方案的生态效益评估。

---

## 一、项目简介

风景园林设计中的"生态效益"常停留在定性描述——说某个方案"绿化效果好"，
却很难给出固碳多少、降温多少、能拦下多少雨水。本项目把这些指标变成**可计算、
可视化、可对比**的结果：

使用者只需在网页左侧选择植物与数量，工具即自动完成生态效益测算，并用图表呈现
结果，同时可调用 AI 生成一段设计层面的分析报告。

面向的场景是**华南地区（广东）的城市园林绿化**：植物库、气候参数、截留率
全部按广东地区实测研究标定，而非套用北方或通用参数。

---

## 二、核心功能

### 1. 三大生态效益计算

| 指标 | 计算方法 | 关键参数 |
| --- | --- | --- |
| **固碳释氧** | 单株日固碳量 × 株数 × 天数 | 释氧系数 2.67（每固定 1 kg 碳释放 2.67 kg 氧）；CO₂ 当量按 44/12 折算 |
| **蒸腾降温** | 蒸腾量 × 汽化潜热 → 吸热量 → 等效降温空气量 | 汽化潜热取 **2404 kJ/kg**（华南夏季实测均值，非通用值 2450） |
| **雨水截留** | 冠层截留贮水量 × 截留率 | 截留率按雨强分档，并内置华南实测对数模型 |

在此基础上还计算了**滞尘量**与**降温能力指数**（库内分位排名）。

### 2. 可视化图表（Plotly，全部支持鼠标悬停查看数值）

- **三维效益雷达图**——固碳 / 降温 / 雨水截留的得分分布
- **贡献占比环形图**——各植物对总效益的贡献比例（可切换指标）
- **堆叠柱状图**——各植物固碳贡献，按乔木 / 灌木 / 地被着色
- **方案 vs 纯草坪基线对比图**——同一面积下方案相对纯草坪的改善倍数

### 3. 分类联动式方案录入

先选「植物类别」（乔木 / 灌木 / 地被），再在该类别下选具体植物，
避免 31 种植物挤在一个长列表里。支持按**株**或**㎡**录入，
选㎡时按单株冠层面积自动折算株数。

### 4. AI 设计辅助报告

调用 DeepSeek API 生成一段 200~300 字的设计分析（整体评价 / 贡献植物识别 /
结构优化建议）。**未配置 API Key 时自动降级为本地规则生成**，功能完整可演示。

### 5. 可调计算参数

雨强档位、实际降水量、地区修正系数（`region_factor`，默认 1.0 = 广东地区）、
核算天数均可在界面上调整。

## 三、数据来源说明

### 植物参数库：31 种华南常见园林植物

| 类型 | 数量 |
| --- | --- |
| 乔木 | 15 种（榕树、细叶榕、香樟、阴香、木荷、秋枫、桃花心木、海南红豆、麻楝、扁桃、红花羊蹄甲、黄槿、白兰、芒果、龙眼） |
| 灌木 | 10 种（大红花、假连翘、马缨丹、黄叶榕、红桑、灰莉、黄金榕、福建茶、龙船花、鸭脚木） |
| 地被 | 6 种（麦冬、鸢尾、白三叶、沿阶草、海芋、春羽） |

每个参数都标注了来源与换算过程（CSV 的 `data_source` 字段），
可追溯到具体文献的哪一张表。

### 参考文献（华南 / 广东地区实测研究）

| 用于 | 文献 |
| --- | --- |
| 灌木固碳释氧 | 林欣等. 18种常见灌木绿化树种光合特性及固碳释氧能力分析, 2014 |
| 灌木冠层截留 | 朱炜晔等. 6种园林灌木植物冠层截留特征研究, 2022 |
| 乔木固碳与降温增湿 | 代色平等. 广州市8种常用园林植物生态特性比较, 2013 |
| 乔木冠层蒸腾与 LAI | 杨士弘等. 广州城市绿化的环境作用, 1996 |
| 乔木形态与降温模拟 | 李江波等. 广州地区典型绿化乔木降温增湿效应研究, 2024 |
| 园林植物滞尘 | 李寒娥等. 佛山市主要城市园林植物滞尘效益分析, 2006 |
| 绿地配置截留率 | 赵峰等. 华南地区不同绿地植物配置方式对其冠层雨水截流能力的影响 |
| 汽化潜热 | 黎国健等. 华南12种垂直绿化植物的生态效应, 2008 |

### 数据分级（已逐项标注）

| 参数 | 广东本地实测 | 近缘种/同科估算 | 生长型估算 |
| --- | --- | --- | --- |
| 固碳 | 11 种 | 10 种 | 10 种 |
| 蒸腾 | 2 种（+1 种定性） | — | 28 种 |
| 截留贮水 | 2 种 | — | 29 种 |
| 滞尘 | 7 种 | — | 24 种 |

> **如实说明**：固碳量有 11 种直接来自广东实测文献；蒸腾与截留的实测覆盖较少，
> 其余为基于同属/同科近缘种或生长型的估算。每条记录的 `data_source` 字段都
> 明确写了属于哪一档、依据哪个值、如何换算，便于核查。

### 两个容易出错的口径（本项目已做处理）

1. **文献中的"固碳量"是 CO₂ 质量，不是碳质量。**
   文献公式用 44（CO₂ 摩尔质量）作系数，故 7~10 g/(m²·d) 指 CO₂。
   本库统一折算为碳：碳 = CO₂ ÷ 3.6667。若不折碳会把固碳量高估 3.67 倍。
2. **"单位叶面积"与"单位绿化面积"是两个不同基准，不可混用**（差 2~3 个数量级）。
   本库对每个数值都记录了基准，再做换算。

## 四、如何运行本项目

### 4.1 环境要求

- **Python 3.12（推荐）或 3.11+**
- 操作系统：Windows / macOS / Linux 均可（本项目在 Windows 11 + Python 3.12.14 下测试通过）

> 检查 Python 版本：`python --version`
> 若提示找不到 python，或 `python` 指向 `WindowsApps` 下的 0 字节占位文件，
> 需先从 [python.org](https://www.python.org/downloads/) 或 Microsoft Store 安装 Python 3.12。

### 4.2 安装依赖

进入项目目录后执行（**推荐使用虚拟环境**）：

```powershell
# 1. 进入项目目录
cd 植物生态效益计算器_提交版

# 2. 创建虚拟环境
python -m venv .venv

# 3. 激活虚拟环境（Windows PowerShell）
.\.venv\Scripts\Activate.ps1

#    若提示"禁止运行脚本"，先执行：
#    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

#    macOS / Linux 用：
#    source .venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

#    国内网络建议加清华镜像：
#    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 4.3 启动

```powershell
# 注意：必须在项目根目录（app.py 所在目录）执行，
# 否则 import modules.* 会失败
streamlit run app.py
```

浏览器会自动打开 **http://localhost:8501** 。

### 4.4 使用步骤

1. 左侧「植物类别」选择乔木 / 灌木 / 地被
2. 「选择植物」选择具体树种
3. 填写数量，选择单位（株 / ㎡）
4. 点击「添加到方案」，可重复添加多个植物
5. 点击「开始计算」
6. 在右侧四个标签页查看结果：核心数据看板 / 可视化图表 / 种植方案明细 / AI 设计辅助报告

### 4.5 可选：配置 AI 报告（不配置也能完整运行）

```powershell
# 临时生效（仅当前窗口）
$env:DEEPSEEK_API_KEY = "sk-你的key"

# 永久生效（需重开终端）
[Environment]::SetEnvironmentVariable("DEEPSEEK_API_KEY", "sk-你的key", "User")
```

配置后重新启动 `streamlit run app.py`，在「AI设计辅助报告」页点击「生成 AI 报告」即可。
**未配置时自动使用本地规则生成报告，页面所有功能均可正常演示。**

## 五、项目结构

```
植物生态效益计算器_提交版/
├── app.py                     # Streamlit 主程序（界面与交互）
├── modules/
│   ├── calculator.py          # 计算引擎（固碳/蒸腾降温/雨水截留/滞尘）
│   ├── charts.py              # Plotly 图表生成（5 类图表）
│   └── ai_report.py           # AI 报告生成（DeepSeek API + 规则降级）
├── data/
│   └── plants.csv             # 植物生态参数库（31 种 × 13 字段）
├── .streamlit/
│   └── config.toml            # 主题配置（配色/字体/圆角）
├── requirements.txt           # 依赖清单
├── setup_env.ps1              # 一键环境搭建脚本（Windows，可选）
└── README.md                  # 本文件
```

### 主要文件说明

| 文件 | 作用 |
| --- | --- |
| `app.py` | 页面布局、侧边栏输入、四个结果标签页、会话状态管理 |
| `modules/calculator.py` | 全部计算公式与物理常数；支持 `region_factor` 地区修正 |
| `modules/charts.py` | 雷达图、环形图、堆叠柱状图、对比图、排名图 |
| `modules/ai_report.py` | 提示词构造、DeepSeek 调用、失败自动降级 |
| `data/plants.csv` | 每行一种植物，含 `data_source` 字段记录文献依据 |

## 七、已知局限

1. **蒸腾与截留参数的实测覆盖有限**：受可得文献限制，这两项多数为估算值，
   `data_source` 已逐条标注，引用时请注意。
2. **不同文献间的固碳量级存在冲突**：代色平等(2013)与杨士弘等(1996)折算到公顷后
   相差约 8 倍，疑与测定年份、光照条件、叶面积指数口径有关。本库同一物种只取
   单一来源，未混用。
3. **蒸腾降温不输出"℃"绝对值**：瞬时降温幅度取决于通风条件，本工具不假设通风，
   改以"可降温空气体积"与"降温能力指数"表达，避免虚假精确。
4. **滞尘量为单个雨水积累周期的累积量**，非日均速率。
5. 雨水截留为**单次降雨**口径，全年累计需按各雨强的降雨场次占比加权。
